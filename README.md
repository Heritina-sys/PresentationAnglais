# PresentationAnglais

Deux présentations PowerPoint réalisées en anglais :

- `DarkWeb.pptx` — présentation sur le Dark Web.
- `DarkWebKali.pptx` — variante de la présentation, orientée Kali Linux.

Ce dépôt ne contient pas de code : uniquement les fichiers `.pptx`. Ils sont
versionnés tels quels (format binaire). Ouvrir avec PowerPoint, LibreOffice
Impress ou Google Slides.

## Contenu

| Fichier | Description |
|---|---|
| `DarkWeb.pptx` | Présentation principale |
| `DarkWebKali.pptx` | Variante orientée outils Kali |
